# ماموریت ساتوشی (Satoshi Quest)

یک بازی گرافیکی اول‌شخص تحت وب با Three.js که در آن نقش یک تریدر ارز دیجیتال را بازی می‌کنید و باید با جمع‌آوری کلیدهای کیف‌پول، ساتوشی را پیدا کنید.

## اجرا

```bash
python3 -m http.server 8080
```

سپس مرورگر را روی `http://localhost:8080` باز کنید.

## ویژگی‌ها

- نمای اول‌شخص + کنترل ماوس/کیبورد
- محیط سه‌بعدی نئونی
- سه ایستگاه داده برای دریافت کلیدها
- هدف نهایی: پیدا کردن کاراکتر ساتوشی
- نمایش آنلاین قیمت BTC از Binance WebSocket (با حالت fallback)
